# 鱼人（Murloc）造型

> 实现正本：`src/presentation/murloc-parts.ts`（零件）+ `voxel-rig.ts` / `dummy-rig.ts`（挂点）
> 配置：`config/game.json` 的 `view.bodyTypes.murloc`（可当主角）、`config/plots/y-murloc.json`（当杂兵）

## 一、为什么是「换几何」而不是「加骨架」

蜘蛛是**另一套骨架**（8 腿、三角步态、两骨闭式解），因为它的运动方式根本不同。
鱼人不是：双足、髋膝踝、肩肘腕、攻击时上半身前压 —— 和人类完全同构。

所以鱼人只换五处几何：

| 部位 | 换法 |
|---|---|
| 头 | 方颅 + 前凸下颌 + 横裂嘴 + 两颗凸眼 + 冠鳍 + 鳃 |
| 背 | 一整片长板背鳍 + 一对肩鳍 + 腹甲 |
| 手 | 宽蹼掌 + 三指 + 指间薄蹼 |
| 脚 | 前后拉长 0.26m 的蹼足 + 三趾 |
| 尾 | 髋后一小截短尾 |

**骨架、骨骼名、IK、步态、挥击、断肢映射、倒杆物理一行不改。** 回报是鱼人天生
会跑、会砍、会掉头、会侧倒 —— 这些能力不需要为它重写一遍。代价是它走路姿势和人类
一样（下一步）。

## 二、抓形：四个辨识点

| 特征 | 做法 | 为什么 |
|---|---|---|
| **大头** | `headSize 0.46 > bodyHeight 0.34 > legLength 0.36` | 鱼人一眼认出来靠「头比身子还横」；三头身的人形比例立刻变「绿皮人」 |
| **钝吻** | 方颅一整块，下颌只前凸 0.16HS | 第一版把吻部做成伸出去的长条，侧视读作**鳄鱼** |
| **凸眼** | 眼窝直径 0.32HS，中心推到 `(±0.24, 0.66, 0.30)`，前缘凸出脸 4cm | 眼睛埋进颅骨内部时，正脸只剩两条黄缝，读作「眉毛」 |
| **鳍** | 冠鳍 + 背鳍都是一整块长板 + 亮色顶边 | 2.5D 俯视看到的是鳍的**顶面**（只有几厘米宽），分片堆叠会读成「一串珠子」 |

配色只有一条规矩：**鳍比身体亮**（`#4fa985` vs `#4f9c78`），顶边再亮一档
（`#9ce0bc`）。全用暗色时鳍和身体渐变糊成一片，现场读作「背上长了一排骨刺」。

## 三、两种出场方式

| 方式 | 怎么开 | 特点 |
|---|---|---|
| 主角 | `?hero=murloc` 或按 `B` 循环体型 | 全套攻击 / 断肢 / 倒地，但主角**没有**受击掉血 |
| 杂兵 | `y-murloc` 工位（三只，血量 90） | 有血条、能被打死、断头整颗掉下来、AI 踱步 |

杂兵走 `DummySpawn.variant`，**只影响表现层骨架**：碰撞半径、身高、AI、血量全按
`dummies.*` 的既有规则走。所以「鱼人比人矮」这件事在 Core 里是不存在的
（`height 1.16` 对 `dummies.height 1.2`，差 4cm 无感）。

## 四、单只假人带血量

`DummySpawn` 新增 `health`（可选）。不填 = 沿用 `dummies.health`（默认 0 = 打不死的
测试桩）。鱼人填 90：`hits.damage.heavy × damageMul` 一刀 18，正好 5 刀。

这条不能反过来做（把 `dummies.health` 全局改成 90）：普通假人是**测距离 / 测 AI 的
测试桩**，被打死会让一堆工位失效。

## 六、已知限制

1. **走路姿势是人类的**：鱼人应该有点「拖步 + 左右摆」，现在和方块人一致。
2. **鱼人杂兵没有手**：`dummy-rig` 的手臂末端本来就没有手掌，蹼掌只做在主角上。
3. **尾巴是静止的**：挂在 `pelvis` 上跟着屁股走，没有独立摆动。
4. **鱼人主角没有断肢**：断肢是假人系统（`SEVER_NODE` 作用于 `dummyRigs`）的能力。
5. 语音 `mrrgllgllgll` 没有 —— 项目目前没有任何音频层。
