# 基础体态（posture）：叠在所有动作之上的那一层

> 「屁股抬高、头胸压低、脊椎接近水平、再弓一道腰」—— 这不是新动画，是一个**静态姿势层**。
> v9s.70 补了一条：体态把躯干压倒 55° 之后，**几何本身**会在骨盆与胸之间裂开楔形缺口，
> 光有角度不够，还得有补块（见 `pose-layers.md` §3）。
> 代码：`CharacterStyle.posture`（`core/types.ts`）→ `voxel-rig` 2.96 / 3.0 段 → `dummy-rig` 同步一份。

## 为什么能叠

`voxel-rig.update()` 每帧的顺序是固定的，体态插在**动态层之后、脊柱拆分之前**：

```
步态 · 受击 · 惯性 · 持械 → 【体态】 → splitSpine（沿脊柱链摊到各级，v9s.72 起缺省 3 段） → 腕部 → 剑身反解 → 足 IK
```

- **之前**：体态会被攻击 / 受击的覆盖层冲掉，打起来就「站起来」；
- **之后**：`splitSpine` 已经按 42/58 把总角摊到腰和胸，体态折进去就是「弓着」，不是「整根斜」；
- **还必须早于足 IK**：抬 / 沉骨盆要靠 IK 反解成屈膝，晚一步脚就跟着骨盆飞。

`hunch`（v9s.52，老人）是同一位置的单通道旧版；两者可以同时用，`posture` 只是多了可组合的分量。

## 九个旋钮

| 参数 | 单位 | 作用 | 实测边界 |
|---|---|---|---|
| `pitch` | rad | 躯干总前倾，经 `splitSpine` 摊成腰 + 胸 | 与动态层合计 **≤ 1.05**（`maxTotal`） |
| `waist` | rad | 拆分**之后**只折腰段 → 塌背的弧线 | > 0.4 胸腔会插进胯块 |
| `headLift` | — | 头反向抬（按实际吃进去的角度算） | 1.0 ≈ 脸水平；**鱼人取 1.12**（世界俯仰约 +14°，抬头 7.7°，38° 俯视下才能露出躯干） |
| `headReach` | m | 颈根前伸，头真的探出去 | > 0.22 头会和胸口脱开一条缝 |
| `neckDrop` | m | 颈根下压，「缩脖子」 | > 0.06 头埋进肩线 |
| `pelvisLift` | m | 抬胯 | **单用必离地**（见下） |
| `pelvisDrop` | m | 屈膝换行程 | > 0.09 时 IK 解不满，脚会压进地面约 2cm（有地板兜底，见下） |
| `pelvisBack` | m | 骨盆后坐 | > 0.06 重心跑到脚跟后面（**鱼人取 0.07**：前倾 55° 必须靠它压住） |
| `armDrop` | 0~1 | 上臂反向回正（按**胸段**角度算） | 1.0 会把胳膊转进胸腔；0.5~0.6 = 手落在身前 |
| `hipShare` | 0~1 | 髋块分担多少腰段俯仰（v9s.70） | 0 = 背面裂开 8.8cm 的洞；1 = 洞挪到骨盆底下；**鱼人取 0.45** |

## 三条硬边界（都是实测出来的）

**1. 抬胯不能靠抬骨盆。** 两骨 IK 的可达上限 = `legLength`，而默认站姿的腿**已经是直的** ——
所以 `pelvisLift: 0.05` 会让脚离地 2.6cm（`postureDebug().footY` 直接量得出来）。
「屁股高」只能靠**躯干压平**：髋不用动，头和胸低下去，臀线自然成为全身最高点。

**2. 屈膝换行程是有限的，但脚不再穿地。** `pelvisDrop` 每加 1cm，IK 残差让脚陷约 1.5mm
（drop 0.09 时 -2.2cm）—— `maxCorrectionDeg` 与权重吃不下更多的弯。
v9s.65 之前这里只能取 **drop 0**（腿伸直），代价是「像一根棍子撑在地上」。
现在足 IK 加了一条**地板兜底**（锚点低于地面时顶回地面，见下），鱼人才敢取 0.06 做屈膝。

**3. 前倾有总预算，因为动作会来抢。** 挥砍自带约 30° 前压，叠在 65° 体态上就是 95°，
实测读作「整个人扑在把上」。所以体态只吃 `maxTotal - 已用`，攻击期间再打五折（`keep`）。

## 足 IK 的地板兜底（v9s.65）

`rig-ik` 的契约一直是「把脚钉在**基准变换下的脚位**」，它不判断那个位置合不合理。
而 FK 给出的脚位本身就可能在地面以下（落地缓冲压骨盆、步态滞后、基准高度差一点），
于是 IK 忠实地把脚钉在地里 —— **越钉越沉，读作「脚掌穿地」**。

修法只加一条下限：`applyFootIK` 收 `groundY`（调用方传角色 `position.y`），
锚点低于它就顶到地面。抬脚 / 迈步的帧锚点在地面之上，这一行不动它们 ——
所以「脚抬起」与「脚贴地」的原有语义都不变。

```
锚点 y = max(FK 脚位, groundY)
```

单测：`tests/v9s65-rig-fix.test.ts`（同一副骨架，锚点 0.2 不动、锚点落到 -0.2 时被顶到 0）。

## 头：yaw 与 pitch 用两个节点（v9s.65）

鱼人的头比身体还横，绕脖子（y=0）做 yaw 时**整颗头像锤子一样甩出去** ——
待机盯人读作「疯狂转头」。但把 pitch 也一起搬到颅中心会坏另一件事：
同样的抬头角不再带来「头向后仰」的位移，脸直接扎到地上（实测头低了 25cm、前伸 25cm）。

所以分成两层：

| 节点 | 管什么 | 绕哪转 |
|---|---|---|
| `headPivot` | pitch（点头 / 抬头补偿） | 脖子（躯干顶） |
| `headYaw`（只在鱼人身上） | yaw（转头看目标） | 颅骨中心（`MURLOC_HEAD_SPIN × headSize`） |

几何在 `buildMurlocHead` 里整体下移同样的量，与节点抬高抵消 —— **位置不变，只有旋转中心变了**。

## 2.5D 俯视下先坏的不是穿地

三头身的髋只有 0.385m，头在 `pitch = 1.8 rad`（103°）时最低点还有 0.36m ——
**头根本啃不到地**。先坏的是**可读性**：头一低就把整个躯干挡在下面，最高点从「头」变成「背」，
俯视相机里读作一坨。所以鱼人停在 55°（`0.72 + 0.24`），不是能压到多少就压多少。

## 鱼人的体态写在代码里

`MURLOC_POSTURE`（`presentation/murloc-parts.ts`）是**唯一真源**，`game.json` 只写 `murloc: true`。
原因：它和头 / 背鳍 / 腿长是配套的，换个数就不像鱼人；而且码头那三只杂兵没有独立造型配置，
写死在一个地方才能保证「主角爬着走，它们也爬着」。

## 验收读数

`view.postureDebug()`（浏览器 `window.__harness.view.postureDebug()`）：

```json
{ "pitch": 0.664, "waist": 0.221, "hipY": 0.385, "headY": 0.643,
  "headZ": 0.271, "footY": -0.015, "reachL": 1.02, "reachR": 0.94, "headLowY": 0.30 }
```

- `reachL/R`：髋→脚 / 腿长。> 1 = 脚被拉离地面；
- `headLowY`：头部子树最低点（不含武器 —— 剑在待机时就垂到地下 15cm，混进来判据就废了）；
- 断言见 `tests/v9s64-posture-sentinel.test.ts`。

## 补偿写在哪个坐标系里（v9s.66）

体态里有两处「反向补偿」：头抬（`headLift`）与手臂回正（`armDrop`）。它们都是绕**父节点**的轴算的。
躯干一旦被偏航（胸随下盘带转、攻击旋身）或侧倾（骨盆 roll），父节点的 X 轴就不再指向角色左右，
同一个角度读起来是「斜着掰」—— 鱼人那种扁宽躯干上尤其明显。

`armDrop` 因此改走**模型空间**（`rig-space.ts` 的 `pitchInModelSpace`）：
父节点没转时与旧写法逐字节等价，转了之后旋转轴仍是模型的轴。
`headLift` 保留局部轴 —— 头本来就应该绕自己的左右轴点，这正是「点头」的语义。

同一次改动还有一项分账：**偏航按 `spine.yawChest`（默认 0.7）给胸段**，俯仰仍走 58/42。
旧版把 `chestYaw` 写进 `upper` 再拆分，胸只吃到 42%（40° 下盘 → 胸 10°），
看起来「胸的朝向根本没变」而腿根转满 —— 详见 [`pose-layers.md`](pose-layers.md) §2–3。

## 已知限制

1. 体态是静态的，不会随速度呼吸；跑起来仍是同一个角度。
2. `waist` 只作用在人形骨架（蜘蛛没有腰）。
3. 体态会把剑的「世界仰角」一起补偿掉（`applyBladeTarget` 里加了实际吃进去的角度），
   但**盾**没有世界角语义，压平后会跟着小臂一起倒。
4. 头前伸不改变碰撞盒：贴墙时头会穿进墙里 15cm 左右。
5. 分两层之后 yaw 轴不再随 pitch 倾斜（这是好事），但**两层之间的间隙没人补** ——
   头抬到极限（`headLift` > 1）时脖子接缝会露出来。
6. `armDrop` 只作用于上臂，小臂与手腕仍由持械 / 腕部滞后层决定：
   举盾时手臂会重新前倾，回正只在待机与步态下明显。
