# 输入与操作

> 最后更新：2026-11-08（v9s.38）。
> 管什么：隐形摇杆、按钮、键盘、轻点拾取、UI pointerId 隔离、手势判定、完整按键表。
> 实现：`src/adapters/input.ts`（DOM 事件 → `Intents`），Core 只读 `Intents`。

## 指针 / 触屏

| 输入 | 效果 |
|---|---|
| 任意非按钮空白区域按住拖动 | 隐形摇杆移动，按下点为原点，拖得越远越快（**满推行程 56px**，可热调；屏幕上不绘制摇杆） |
| 轻点（不拖动）某个角色 | 循环切换该角色行为：普通假人 5 种（游走 → 跟随 → 保持距离 → 攻击 → 待机），持械陪练 6 种（多一个「陪练」） |
| 左上「工位」胶囊 | 展开 7 个测试工位，点名字一键传送（相机瞬移，不跨场地滑行） |
| 右下按钮簇 | 攻击 / 技2 / 冲 / 跳；复位单独放角落防误触 |
| 双指张开 / 捏合 | 相机拉远 / 拉近（相对移动 <18px 不确认，防掌根误触）；滚轮与 `=` / `-` 等价 |

## 键盘速查

| 键 | 作用 |
|---|---|
| `WASD` / 方向键 | 移动（与摇杆同一套映射） |
| `J` | 攻击（按住 = 自动连击；法杖施法1；弓按住蓄力） |
| `K` | 技2（法杖施法2） |
| `Shift` | 按下沿 = 翻滚 / 闪现；按住 = 持续加速跑 |
| `空格` | 跳跃 |
| `1`–`5` | 剑盾 / 双剑 / 大剑 / 法杖 / 弓 |
| `6`–`9` | 切换 1–4 号普通假人的行为（历史便利键；其余单位用鼠标点） |
| `[` / `]` | 上一个 / 下一个测试工位 |
| `\` | 召回全部假人（回工位、恢复初始行为、清攻击状态） |
| `R` | 复位（玩家 + 全部 9 个单位 + 战斗 / 朝向 / 目标 / 受击 / 冲刺） |
| `=` / `-` | 相机拉远 / 拉近（与滚轮等价） |
| `B` | 循环体型（与顶部「体型」胶囊同一入口） |

## 四条容易踩的输入规则

> **冲刺有两条输入沿**：`sprintPressed`（按下沿）触发一次翻滚 / 闪现，`sprintHeld`（按住）是持续加速跑。低帧率一帧多步时按下沿只在第一个 step 生效，不会一次按键触发多次冲刺。

> **点击与拖动靠位移区分**：在角色身上「按下后拖动」仍然是摇杆移动，**不会**切换模式；只有按下到抬起位移小于 **8px** 的轻点才算一次点击。

> **按钮区不干扰摇杆**：整个按钮容器（含按钮间隙、padding）标了 `data-ui-region`，在这些区域按下的 pointerId 会被记入隔离集合，全程不参与摇杆与轻点判定。一根手指拖摇杆、另一根按技能时，移动方向不会跳变。

> **失焦要连键盘一起清**：`releaseAllInputs()` 在 `blur` / 切后台时清 pointer、摇杆、按钮，**也清 `keys`**（v9s.75 补的）。漏清键盘的后果是双份的：角色一直朝旧方向走，且残留的 `j` 会被 `onKeyDown` 的 `keys.has(k)` 去重吞掉 —— 切回窗口后攻击键要重按一遍才恢复。

尺度常量（改之前先看这里）：摇杆满推 **56px**、死区 **0.08**、点击阈值 **8px**、捏合确认 **18px**、技能按钮瞄准死区 **16px**。

#### 横屏 / 竖屏布局

- **横屏**：HUD 在左上、提示紧随其下，武器条顶部居中，左下「冲/跳/复位」，右下「技2 / 攻击」，右上调试面板。
- **竖屏**：攻击与技2 **从上到下纵向排在屏幕右侧**（技2 在上、攻击大按钮在下，单手拇指可及）；武器条独占顶部；HUD 自动切换成 **7 行短版**并下移到武器条下方；收起的调试面板再放到 HUD 下方，三者互不遮挡。
- HUD 与提示共用同一个纵向容器（`#overlay-left`），提示永远紧贴 HUD 下方，**不再依赖绝对 `top` 定位**，因此任何字号/换行都不会再出现重叠。

左上角 HUD 横屏显示 `tick / pos / vel / grounded / sprint / facing / orient(face·body·head·move·head-body) / move / stick / aim / weapon / phase / combo / chan·bolts·rings / atk / **dash** / **camera** / target / charge / dummies / atkCount / hit / hurt / impulse / event`；竖屏为精简短版（保留 target / hit / hurt / dash / camera 等验收关键项）。
