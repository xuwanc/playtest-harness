# 哨兵机（Sentinel）：我自己挑的那个角色

> 用户说「你也可以做一个你喜欢的角色造型，我会一直帮你保留在游戏里」。
> 我挑了**一台锈掉的巡逻哨兵机**。代码：`presentation/sentinel-parts.ts`（约 200 行，零动画），
> 出场：`?hero=sentinel`，或游戏里按 `B` 循环体型。

## 为什么是它

三条自己给自己定的规矩，和鱼人那轮是同一套：

| 规矩 | 做法 | 为什么 |
|---|---|---|
| 大块抓型 | 头 = 一块方颅；躯干 = 一块胸甲板 + 一个背包 | 俯视下角色只有 ~200px 高，细节过 6 块就成噪点 |
| 小块点缀 | 灯条 / 天线 / 三根警示条 / 侧栅 / 腰侧液压杆 | 全挂在**轮廓线**上，缩到最小也还剩剪影 |
| 一眼不同 | **只画一只**灯眼 | 人、鱼人、老人都是两只眼；一只横灯立刻读作「机器」 |

骨架照旧是人类的（双足、髋膝踝 / 肩肘腕），所以它会走、会砍、会受击、会倒地 —— 白拿。

## 两处走过弯路的地方

**1. 眼睛不是「方框 + 方窝 + 小灯」，是「一条黑带 + 一条亮灯」。**
第一版按人脸的思路做了三层套盒，俯视 200px 下三层互相吃掉，读出来是一块深色铁皮。
改成一条贯穿正脸的面罩暗带，里面一条 0.66×0.115 的发光横条（`emissiveIntensity 2.2`），
缩到最小仍是两道线 —— 这是「Cylon 式」单眼的唯一原因。

**2. 排气管不能长在头顶。**
第一版把两根 `0.34` 长的锈色管子竖在背包上沿，正面看就是**一对鹿角**。
现在横着从背包两侧伸出（`rotation.y = ±0.5`），只在侧后 3/4 露出来。

## 身体比例

`height 1.44 = leg 0.62 + body 0.42 + head 0.40`，`bodyWidth 0.52`（比人宽 13%）。
矮壮 + 大头 = 机械感；拉高会变成「穿铠甲的瘦子」。

体态用的是本轮的 `posture` 层：`pitch 0.14 / headLift 0.6` —— 微微前探，像常年站岗的旧机器。

## 灯眼不打红光

灯条材质打了 `userData.glow`，受击闪光（`dummy-rig` / 主角的 mats 遍历）会跳过它。
机器被打的时候灯**不该**变红，它应该一直亮着 —— 这是它「还活着」的唯一信号。

## 已知限制

1. 没有 `DummyVariant`：只有主角能出场，还不能当杂兵（加一个变体要动 `DummyVariant` 与工位配置）。
2. 夹钳只是两片斜板，没有开合动画（手部没有骨骼，做不了）。
3. 天线不随速度摆动（没有次级动力学节点）。
4. 腰部液压杆是静态几何，弯腰时跟着胸段刚性转动，不会「伸缩」。
