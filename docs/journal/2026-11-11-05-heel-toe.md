# 脚掌会折了：heel-toe roll（v9s.76）

> 2026-11-11。`animation.md` 里「重量感」那条挂了三轮，最大的一块一直是
> **脚是刚性一块板**：落地「拍」、蹬地「抬」，中间没有任何过渡。

## 1. 病

`voxel-rig` 的鞋是一块 `makeBox`，整只挂在踝上。于是支撑期 0.3 秒里，
脚相对地面只有「平移」，没有「滚动」——真实步态是脚跟先着地、重心压到前掌、
再以脚尖为支点蹬离，接触点一路往前滚。

视觉后果不是「不好看」，而是**读不出重量**：一块板拍在地上和一根羽毛拍在地上
是一样的，重量只能靠镜头抖动去补。

## 2. 做法

**骨架**：`ankle` 下多一个 `ball` 关节，脚掌几何从 60% 处切成两段 ——
后掌挂踝、前掌挂 `ball`。蹼足 / 机械脚整只挂踝（`toeLen = 0`），
`ball` 是空节点，读作「这一体型没有脚掌分段」。

**曲线**（`gait.ts` 的 `heelToeAngle(s)`，s = 支撑进度 0..1）：

| s | 阶段 | 折角 |
|---|---|---|
| 0 → 0.18 | 脚跟着地 | −14° → 0（`u²` 收尾，脚尖上翘逐渐放下） |
| 0.18 → 0.55 | 全掌贴地 | 0 |
| 0.55 → 1 | 蹬离 | 0 → +26°（脚尖下压、脚跟抬起） |
| > 1 | 摆动期 | 0（脚在空中不该折） |

**权重**：`max(attackBlend, speed/1.5)`，两头都要 —— 站定时 `gaitPhase` 是冻的，
不乘权重会把某个相位的折角永久留在待机姿态上（脚一直翘着）；攻击跨步期间
`gaitSpeed` 是 0，只看速度就完全不折。

**抬踝补偿**（`4.05 heel-toe lift`）：蹬离时前掌下压会把脚尖送进地里，
按 `sin(折角) × 前掌长 × 1.8` 把踝抬回来。系数大于 1 是因为这一相位腿还在
往后伸、踝被步态压低，光补几何那一段不够（实测 1.8 倍才把脚尖从「沉入 8cm」
拉回基线量级）。

## 3. 三个坑

**① 黑靴子拍不出来。** 折角 8° 在 0.18m 的脚上前掌只抬 1.2cm，截图里黑靴子
叠在暗背景上完全分不出「脚尖入地 1cm 还是 3cm」。所以加了
`gaitDebug().footMinYL/R`（`Box3` 量整只脚的世界最低点）—— 这个数才是验收判据，
截图只用来兜「有没有撕裂」。

**② 0.9m 的机位会直接怼进盾牌。** 第一版脚部特写拍出来一片灰，就是盾的内侧面。
拍脚之前先 `traverse` 掉 `shield|sword|blade` 的可见性。

**③ 想钉住相位不能用「按键走 + 每帧改 gaitPhase」。** rAF 与 `render` 的先后顺序
不保证，Core 每帧还在推进相位 —— 钉 0.045π 实拿到 0.43π，三张图的折角全是 0。
正解是 `debug.paused = true`：它只停 `step`，`render` 照常每帧调 `rig.update`，
相位与速度都由我们钉死（实测 −7.9° / 0° / +17.6°，与曲线解析值逐位一致）。

## 4. 验收

| 项 | 结果 |
|---|---|
| `npx vitest run` | **131 文件 / 1328 例**（新增 `v9s76-heel-toe` 7 例） |
| 曲线连续性 | 256 点扫过支撑期，最大步进 0.61°（阈值 0.8°） |
| 三相位折角 | s=0.045 → −7.9°，s=0.36 → 0°，s=0.92 → +17.6°（与解析值一致） |
| 脚最低点 | 蹬离 −0.065m（同相位基线约 −0.037m）；静止 / 全掌 −0.009m |
| 通道守卫 | `2.82 heel-toe` 只写 `ballL/R.rx`，六场景零越权 |
| 确定性 | golden hash 未变（`ball` 是表现层节点，不进快照） |

## 5. 已知限制

- **蹬离相位仍比基线低 3cm**：抬踝是「几何补偿 + 经验系数」，不是真正的滚动 IK。
  根治要把 IK 锚点从「踝原点」挪到「当前接触点」（脚跟 → 前掌随相位移动），
  那会动到零滑步的假设，得单独一批做。
- **只有人形鞋分段**：蹼足 / 机械脚还是整块。
- **参数没进配置**：`HEEL_TOE` 是模块常量（14° / 26° / 0.18 / 0.55）。
  手感看几轮定下来再迁 `config/game.json`，否则每调 1° 都要改 schema 与夹具。
