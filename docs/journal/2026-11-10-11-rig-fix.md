# v9s.65 · 看着画面报的七条造型问题

> 上一版（v9s.64）所有验收数字都是绿的：`postureDebug` 的 `footY` 是 -0.015m（1.5cm 误差，
> 「可接受」），`reachL 1.02`（「没超上限」），雕塑比例也都在区间里。
> 但把画面截出来一看，七处全错。**这轮没有一条新功能，全是「数值没报错、画面上错」**。

## 七条 / 七种错法

| 报的现象 | 真正的错因 | 修法 |
|---|---|---|
| 头看着像在疯狂转 | yaw 绕**脖子**（头底）转，头比身体还横 → 整颗头像锤子甩出去 | 拆两层：`headYaw` 绕颅中心、`headPivot` 仍绕脖子管 pitch |
| 腿绷得像棍子 | `pelvisDrop` 被我锁死为 0（怕脚穿地） | 开 0.06，同时补足 IK 地板兜底 |
| 屁股不自觉往前栽 | 前倾 55° 的力矩没有配重 | `pelvisBack 0.02 → 0.07` |
| 武器拿在脚附近 | 躯干压平，上臂**跟着胸段**一起倒向地面 | 新增 `armDrop`：上臂反向吃掉一部分胸段俯仰 |
| 尾巴中间少一节 | 两段「首尾相接」差 1.1cm，被尾鳍 0.36 的倾角放大成 4cm | 两段重叠 5.4cm |
| 哨兵机腿插进脚掌 | `ankleY` 传的是**米**，却跟着 `add()` 一起乘了 `headSize`：-0.31m → -0.12m | 三个件先按踝点 0 摆，再整体搬到 `ankleY` |
| 哨兵机钳子像螯 | 两片爪沿 **Z**（前后）张开 | 改沿 X 左右夹，开口 0.34 → 0.22 |

外加一条通用问题：**足 IK 会把脚钉进地里**。

## 那条通用的：IK 只保证「钉在基准脚位」

`rig-ik` 的契约从头到尾都是「把脚钉在**步态基准下的脚位**」，它不判断那个位置合不合理。
而 FK 给出的脚位本身就可能在地面以下（落地缓冲压骨盆、步态滞后、基准高度差一点），
于是 IK 忠实地把脚钉在地里 —— **它不是导致穿地的原因，它是让穿地无法自愈的原因**。

修法只加一条下限，不动解算：

```
锚点 y = max(FK 脚位, groundY)      // groundY = 角色 position.y
```

为什么不能改解算：整套 IK 有一条恒等性 ——「权重 0 时结果等价于 FK 角度」，
`ik.test.ts` 与 `v9s33-foot-slide` 都在守它。改解算会同时破坏这条和「脚钉在原地」的语义。

## 头：yaw 与 pitch 必须分层

第一次尝试是**整个 pivot 抬到颅中心**（几何下移同样的量，位置不变）。
结果画面里的头直接扎到地上：头低了 25cm、前伸 25cm。

原因是绕底部转 -54° 时，头会**向后上方位移**；绕中心转 -54° 时头不位移。
同样的 `headLift 0.98`，前者的位移补偿掉了「脸朝下」，后者没有。

所以拆成两个节点：

| 节点 | 管什么 | 绕哪转 |
|---|---|---|
| `headPivot` | pitch（点头 / 抬头补偿） | 脖子 |
| `headYaw`（仅鱼人） | yaw（转头看目标） | 颅中心 |

两个节点各管一个轴，互不干扰 —— 这是这次唯一「结构性」的改法，其余六条都是数值或坐标基准。

## 顺手发现的一条：鱼人杂兵是一颗绿头接在蓝身体上

`dummy-rig` 里只有头 / 躯干 / 脚附件吃了鱼人固定色，**四肢仍走「每个假人专属色」**。
上一版截图里看不出来，因为躯干压平后几乎全被头挡住；这轮换了机位才暴露。
修法：加一个 `cc`（鱼人时 = 固定色），四肢 / 眼 / 鞋全走它。

## 教训

1. **「可接受误差」要拿画面复验**：1.1cm 的尾巴缝、1.5cm 的脚陷，在数字上都是「小」，
   在画面上都是「一眼看出」。验收不能只有读数。
2. **换旋转中心 ≠ 换角度**：同一个角度，绕底部转与绕中心转，位移完全不同。
   想改手感只改一个轴，别把另一个轴一起搬。
3. **单位混用要在一个函数里看得见**：`sentinel-parts` 的 `add()` 默认乘 `HS`，
   `ankleY` 是米 —— 这类混用在调用处看完全正常，只有量出来才知道错了 2.5 倍。
4. **IK 不是「防穿地」，是「防滑」**：它的保证是相对基准的不动，不是绝对高度的正确。
   任何「脚应该在地面上」的期望，都必须另外给一个地板。
