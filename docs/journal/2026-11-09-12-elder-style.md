# 驼背老人：把「造型」从尺寸扩展到体态与配饰

2026-11-09 · v9s.52 / v0.9.73

## 需求

> 弓着腰、膝盖微微前屈、有胡子、头小点、地中海、胳膊腿瘦高、因为弓腰所以只比正常角色高一点、
> 很长的白胡子带一点物理、box 不要太多抓住特征就行。

## 先回答「系统支不支持」

改造前只支持**尺寸 + 配色**（`bodyTypes.<id>.voxel` 六个数值 + `colors` 覆盖），
形态特征是零 —— 驼背、发型、胡子一个都表达不了。

延伸方式是加一层 `VoxelConfig.style`，**不改骨架、不改动画数据**：

```ts
hunch / kneeSink / headScale / balding / hairColor / beard / beardColor
```

关键约束：缺省时骨架与旧版逐字节一致。做法是所有新几何都乘「默认 1」的比例、
所有新姿态都包在 `if (hunch > 0)` 里 —— 于是 1021 例既有测试一条都不用改。

## 三处「不直觉」的实现选择

1. **驼背不是一整根斜**。`hunch` 加在 `splitSpine()` 之前，被脊柱按腰 58% / 胸 42% 拆开，
   视觉上是两段弯折。头再反向抬 `hunch × 0.55` —— 驼背的人抬眼看人。
2. **屈膝不写膝角**。给一个 `kneeSink`（骨盆下沉 5cm），让足部 IK 把脚钉回地面，
   膝盖自然被压出前屈。写死膝角会和步态 / 受击 / 落地缓冲互相打架。
3. **胡子挂点必须离开胸腔**。躯干半深 0.14，第一版挂在 z=0.10 —— 整条胡子埋进身体里，
   截图里「看不见胡子」。改到 `max(HS×0.5, 0.135)` 才露出来。

## 盒子预算

10 个：两鬓 2 + 后脑 1 + 顶后半圈 1 + 白眉 2 + 胡子 3 节 + 脖子 1。
判据是「远看一眼能不能读出老人」，不是细节数量。第一版还试过给腹部做 8 层渐变色，
结果是「蛋糕塔」—— 同色堆叠 + 单一方向光才能融成体积。

## 物理

胡子是 3 节链，每节一个二阶弹簧（`ω=11, follow=0.82`），驱动量是本帧速度差分。
二阶而不是 lerp：滞后来自惯性，一阶只会「慢半拍」，加速时没有「甩出去再荡回来」。

## 验收

- 102 文件 / 1021 例全绿（含新增 7 例）
- 盒子增量 10、驼背角 ≈ hunch、下沉量 ≈ kneeSink、胡子起步 0.15s 后 > 0.03 rad
- `shots/elder/01-front.png` 等 4 张：正面 / 侧面 / 背面 / 走路

## 还欠的

- 胡子只吃前向加速度，左右甩动（转身）还没接 —— 转身时胡子应该横向扫。
- 前肢挥击（剑 / 杖）时胡子会被手臂穿过，没有做碰撞回避。
