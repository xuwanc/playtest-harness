# 收窄、长高，把胡子「欠的两条」补上

2026-11-10 · v9s.54 / v0.9.75

## 需求

> 看上去有点太宽了些 在高一点，且把你之前说的欠的补上，两肩的盒子也有点大了些？

三条尺寸 + 两条遗留。尺寸一次就调对了，遗留的两条各花了一轮才稳。

## 一、收窄 + 长高

上一版是「宽 0.50 / 高 1.32」，横向过冲了：`bodyWidth 0.50` 比标准 0.46 还宽，
1.32 的身高又不够撑住这个宽度，读出来是「矮胖的宽肩老人」。

| | v9s.53 | v9s.54 | 标准 |
|---|---|---|---|
| height | 1.32 | **1.46**（+11%） | 1.20 |
| bodyWidth | 0.50 | **0.44**（−12%） | 0.46 |
| legLength | 0.60 | **0.74** | 0.40 |
| armLength | 0.60 | **0.68** | 0.42 |
| 腿占身高 | 45% | **51%** | 33% |

宽回到标准以下、腿拉到近一半身高 —— 「瘦高」这一次是由比例给出的，
不是靠把横向尺寸砍到营养不良。臂长跟着腿长走（0.68），否则手会够不到膝。

> 身高必须按**实测头顶高度**定，不是按配置的 `height`：驼背 18° + 屈膝 5cm 会吃掉
> 近 20cm。1.40 时实测头顶只有 1.21m，与标准角色（1.11m）几乎持平 —— 等于没变高；
> 提到 1.46 后实测 1.19m，视觉上才算「高一点」。

躯干深度公式 `0.28 × clamp(bodyW/0.46, 1, 1.4)` 在 0.44 时夹到 1，
所以这一版侧面厚度与标准相同（0.28）。**没有跟着一起变薄**，否则收窄会变成「纸片人」。

## 二、肩甲缩小：判据是「外缘与臂外缘齐平」

上一版 `1.35t` 宽 + 中心 `0.4t` → 外缘 `bodyW/2 + 1.075t`，比手臂外沿还多出 4mm，
渲染出来是一对横插的翅膀。这一版 `1.2t` 宽、`1.1t` 高、深 `0.40·bodyW`：

```
外缘 = bodyW/2 + 0.4t + 0.6t = bodyW/2 + t   ← 正好等于手臂外沿
```

于是它读作「肩头加厚」而不是「护肩」。这比「感觉小一点」可复现。

## 三、胡子横向：不是加个 sin，是换坐标系

v9s.52 只吃 `speed`（标量）的差分，所以胡子只会前后晃 —— 原地转身时像一根焊死的板。

改成把**世界速度投影到角色局部**，纵向喂 pitch、横向喂 roll，再加转身的切向
`ω × r`（r 取胡子质心到颈轴的水平距离 0.18m，系数 30 放大到看得见）。

三个坑，一个比一个隐蔽：

1. **不投影就会「假加速」**：世界速度不变、人在原地转身，标量 speed 不动但方向变了；
   反过来，用世界分量做差分则会把转身算成一次纵向冲击。必须 `vF = vx·sinψ + vz·cosψ`。
2. **yaw 差分要回绕**：`atan2(sin Δ, cos Δ)`。±π 处直接相减会瞬间冒出几千 rad/s，
   胡子会被一巴掌扇到限位。
3. **`rotation.z` 的正负号与直觉相反**：正 = 下端偏向角色**右侧**。向右加速时胡子应该
   被拖向**左**，所以驱动要取 `−aR`。第一版写成 `+aR`，观感是"胡子抢在身体前面冲出去"。

还有一个「没有数值 bug、只有观感 bug」的细节：站定时 Core 仍有毫米级的速度与朝向收敛，
不做死区的话胡子每帧被推一点点，30 帧漂出 0.0012 rad。加了 0.6 rad/s² 的死区。

## 四、手臂避让：把 y 写成「带」

挥剑时手从胡子中间穿过去。做法是把根节往「手的反侧 + 后方」推，判据是手在
头部局部坐标里的位置，三个窗口同时命中：伸到脸前（`z > 0.05`）、横向够近（`|x| < 0.3`）、
落在胡子高度带。

第一版把 y 写成 `clamp((0.06 − y) / 0.45)` —— **越低越算威胁**。结果自然垂在身侧的
双手（`y ≈ −0.66`，早就低于胡子末端）被判定成威胁，静止时胡子一直往一侧偏。
改成「围绕 −0.23 的带、半宽 0.3」才正确。

这类错误的共同点：**只想了一个边界，忘了另一个**。

## 五、静止呼吸

`style.breath`：站定时躯干厚度 ±2%、周期 4.5s；速度 > 0.6 归零。

写 `scale.z` 不写旋转 —— 旋转会和脊柱拆分 / 足部 IK 抢同一根骨头；
缩放不进 Core、不影响任何姿态通道，是最「不打扰」的表达方式。
幅度再大就成「喘」，2% 是反复看截图后的上限。
