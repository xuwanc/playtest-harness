# 给动画层加一把「谁允许写哪根骨头」的锁（v9s.74）

> 2026-11-11。上一批（v9s.73）把攻击层改成四元数增量，顺手修了 `upper.rotation.y`
> 归零吃掉持械站姿的 bug。修的时候意识到：**这类 bug 没有任何机制会拦住它** ——
> 表现只是「侧身站没了」，不报错、不崩、单测也测不到。这批解决的是这件事。

## 1. 病根：顺序写在编号里，归属写在记忆里

`voxel-rig.update()` 从第 2500 行到 3500 行是一条流水线，二十多层按注释编号执行
（`2.05 → 2.85 → 3.55 → 4`）。编号就是顺序，但「这一层准不准写 `upper.rotation.x`」
只存在于注释和写代码那个人的脑子里。

于是反复出现两类：

| 类型 | 实例 | 为什么没被发现 |
|---|---|---|
| 越权 | v9s.73 `applyCombatPose` 每帧 `upper.rotation.y = 0` | 值从 0.12 变 0.03，仍然「像个正常站姿」 |
| 双覆盖 | 两个 `=` 语义的层同帧活跃 | 后者吃掉前者，调参时表现为「改 A 没反应」 |

v9s.73 是靠人肉对比 `torsoYawOf` 才发现的。下一层（例如「体态进 base」）会再踩一次。

## 2. 做法：在层边界采快照做差，帧尾比对声明表

```text
beginFrame() → 读快照
每层边界 mark(id) → 再读 → 与上一段做差 → 这层实际写了什么
endFrame()  → 声明 vs 实测 → overreach（越权）/ conflicts（双覆盖）
```

三个决定：

**① 只监控 7 个节点**：`root / pelvis / lower / upper / chest / ankleL / ankleR`。
手臂不在内 —— v9s.73 已经证明手臂不能走四元数增量（`shoulder` 是 `YXZ`，抬臂 −1.9 rad
时四元数→欧拉翻支），多层覆盖手臂是**设计**，纳入监控只会产生噪声。

**② 判据是「值变了」而不是「被赋值了」**。读 Three 的 `position` / `rotation` 做差，
不拦截 setter（Three 内部读写太密，代理的代价不值）。代价：某层每帧写同一个数，
第二帧起就不算写 —— 这只影响 `unused`（信息项），不影响越权与冲突。

**③ 引入第四种语义 `derive`**。`splitSpine` / `distributeYaw` 必然改写上一层写的
`upper.rotation`，但那是「把总角重新摊到骨链上」，不是「抢所有权」。
标成 `override` 会让它和 `2.0 combat` 天天报冲突（第一版就是这样），
标成 `add` 又不诚实（它确实在减少值）。于是单列一类，只参与越权判定。

## 3. 踩的坑

**① 层边界插漏了，归因全错。** 第一版只在「有注释编号」的地方 `mark`，结果
`1.1 stance` 抓到了从 reset 到 stance 之间的**所有**步态写入（`pelvis.px` 出现在
stance 里）。补了 `1.2 gait` / `1.3 stop` / `1.5 inertia` / `1.7 posture-pelvis`
四个边界之后才归因正确 —— 这一段本来没有编号，是「步态解算 + 写入」和
「IK 基准捕获」之间的代码。

**② `2.8 step` 是死路径。** 线上 `config/game.json` 的 `attack.lowerBodyWeight = 0`，
挥击跨步走的是「等效步态」那条，`2.8` 整段不执行。只在测试里把权重改成 0.5
才 dump 到它写 `pelvis.px/py/rz`。

**③ 测试差点假通过。** 探针默认关闭，如果构造 rig 时忘了开，`animProbe()` 返回
`null`，`violations` 永远是空数组 —— 测试全绿但什么也没检查。补了一条
`expect(rep.layers.length).toBeGreaterThanOrEqual(15)` 先证明探针在跑。

**④ 矩阵导出测试的列数算错。** 表头里有一个「层」列，`split('|')` 之后
通道数 = `length - 2` 会多算 1。

## 4. 有效性自检

删掉声明表里 `2.95 facing → upper.rx` 这一条，测试立刻红，且**点名到层与通道**：

```text
AssertionError: expected [ '越权 2.95 facing → upper.rx' ] to deeply equal []
```

这是这批的验收标准：守卫要有牙，不是装饰。

## 5. 实测数据

| 项 | 结果 |
|---|---|
| 监控节点 / 通道 | 7 节点 / 28 通道（root 只监控 `ry`，chest 只监控旋转，踝只监控旋转） |
| 注册层数 | 23 层（含 3 个「不在监控集」的层，登记为空以留位置） |
| 六场景跑完 | `overreach` 空、`conflicts` 空 |
| 全量单测 | **127 文件 / 1303 例**（新增 1 文件 9 例），零回归 |
| 线上开销 | 关闭时每层一次空函数调用；`animProbe()` 返回 `null` |

## 6. 下一步

1. 这张表现在能回答「谁在写 `upper.rx`」，下一步是让它**可执行**：
   `lean` 独立权重、体态进 base 这两件事都要加层，先把声明补齐再加。
2. 逐层 mask（按偏航来源分）落地时，`derive` 语义正好可以扩成「按 mask 重分配」。
3. 稳态重复写同值抓不到（§2 ②）—— 如果将来出现「某层每帧把值写回同一个数、
   却挡住了别人」的 bug，才值得上 setter 拦截。
