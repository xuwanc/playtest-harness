### v9s.16 · 箭矢 / 飞弹 / 斩击弧：先让它「看得见」

> 反馈：① 弓箭有时候完全看不到，只在某条地上的线上看到一点光飞过去，攻击特效也一样；
> ② 冷却期间再按攻击，冷却结束后不会接着蓄力。

#### ① 为什么箭会「变成一条地上的线」

三个原因叠在一起：

| 原因 | 表现 |
|---|---|
| **实体太细** | 箭是一根 3.5cm × 3.5cm × 50cm 的盒子。2.5D 斜俯视下，朝屏幕下方飞（正对镜头）时被投影成 1~2px 宽的竖线，且因为更靠近相机，屏幕位置掉到脚下方 —— 读起来就是「地上有条线上有个光过去」 |
| **没有方向 / 速度信息** | 纯色细杆既没有箭头也没有拖尾，看不出往哪飞、多快 |
| **父节点会把空中的箭拽偏** | 箭原本是 `fxAnchor` 的子节点，锚点朝向在释放动作结束时从 `attackFacing` 切回 `bodyYaw`；蓄力不足的慢箭（8.4 m/s、飞满 9m 要 1.07s）还在空中就被整体旋走 —— 看着像半路拐弯 / 消失 |

#### ② 改法：世界坐标 + 三层可见性

- **世界坐标独立飞行**：起手瞬间把「弓口位置 + 锁定朝向」快照下来（`presentation/fx-shot.ts` 的
  `shotOrigin / shotPoint / shotFade`，纯函数、零 three、可单测），之后每帧自行推进，与父节点、角色转身彻底解耦。
- **有形状的箭**：箭杆 + 四棱箭头 + 一对交叉尾羽，全长 0.72m（与角色身高同比例）。侧看是箭、俯看是亮色短杆。
- **恒面向镜头的柔光**（兜底）：Sprite + 径向渐变 + 加色混合，直径 0.5m。哪怕箭杆正对镜头被压成 1px，光晕仍有约 30px 面积。
- **锥形拖尾**（方向）：向尾部收细的开口圆柱 + UV 渐变贴图，长 1.05m —— 拖尾负责读速度方向，光晕负责「一定看得见」。
- **飞弹同构**：二十面体核心 + 2.5× 半径光晕 + 3.4× 半径拖尾，整组朝飞行方向（只有核心自转）。
- **斩击弧加粗**：管径 0.045 → 0.075，另叠一层 1.09× 的加色光晕；俯视下不再是 1px 细线。
- **末端淡出**：射程最后 1.4m 线性收不透明度，不再是「飞到 9m 啪一下消失」。

所有尺寸 / 颜色都在 `config/game.json` 的 `view.projectiles` 里，可整块拉 0 对照旧观感。

#### ③ 冷却期按键：`bowQueued`

旧逻辑只在 `phase === 'idle'` 时接受 `attackPressed`。而弓箭的后摇是
`windup 0.04 + active 0.12 + recovery 0.26 + settle 0.16 ≈ 0.58s`，这段时间里按下的那一下被直接过滤；
等回到 idle，`attackPressed` 的「按下沿」早已过去，于是**按住也不会开始蓄力**。

现在把按下沿记进 `combat.bowQueued`：回到 idle 且仍按住 → 同一帧开始蓄力（不再需要重按）；
提前松手 / 换武器 / `warpTo` 则丢弃缓冲。刻意只认「新的按下沿」—— 单纯 `attackHeld` 不会自动续蓄力，
否则按住不放会变成无限连射。

#### 验收

- 新增 9 例：缓冲的四种时序（按下并按住 / 按下后提前松手 / 只按住无按下沿 / 换武器与传送清缓冲）、
  满蓄释放回归、箭矢飞行的起点 / 等距推进 / 末端淡出纯函数。
- 全量 **53 文件 / 617 例**通过；`verify:portable` PASS（Core 仍零 three / DOM / 上层依赖）。
- 实拍同一支箭的三个朝向（朝镜头 / 侧向 / 背向）与三个距离（1.2m / 2.4m / 4m）：都不再是细线；
  飞弹是带拖尾的青色光球；斩击弧明显加粗。
- 运行路径复验缓冲：后摇中按下并按住，`t=0 phase=windup queue=true` → `t=45 phase=idle charging=true charge=0.15`。

### v9s.17 · 奥术改成波次齐射，弓箭改成真弹道

> 两条需求：① 奥术飞弹改成「每波 3 个带轻微转向修正的菱形飞弹、一次引导 5 波、结束 / 打断有 1s 冷却」；
> ② 弓箭弹道带重力，打到目标身上插在身上、或落地插地上，并减少蓄力时间。

#### ① 奥术：从「按住无限单发」到「一次 5 波齐射」

旧版 `fireInterval = 0.28s` 单发、按住就一直射，没有段落感。现在：

| 参数 | 默认 | 含义 |
|---|---|---|
| `perWave` | 3 | 每波几枚（波内按 `spreadDeg` 均匀散开） |
| `waves` | 5 | 一次引导几波（5 × 3 = 15 枚） |
| `waveInterval` | 0.2s | 波间隔；第一波在按下瞬间就发 |
| `spreadDeg` | 5° | 同波相邻两发的夹角（三发合计 10°） |
| `homingRange` / `homingConeDeg` | 8m / 40° | 发射时在这个锥形里选**最近**的假人做目标快照 |
| `turnRateDeg` / `homingTime` | 420°/s / 0.35s | 出膛后 0.35s 内允许转向，之后锁定直飞 |
| `cooldown` | 1.0s | 放完 / 松手 / 被打断后统一进入 |
| `radius` | 0.3m | 命中半径（视觉由 `view.projectiles` 再收一圈） |

**为什么是「限时制导」而不是「一直追」**：转弯半径 = 速度 / 角速度。
14 m/s + 150°/s ≈ 5.3m 半径，对 5m 外的目标根本转不过来，飞弹会绕着目标画圈、永远打不中
（实测偏差一直停在 0.29 rad）。所以两者一起调：角速度提到 420°/s（半径 ≈ 1.9m，够修正 20° 偏角），
再加 `homingTime` 截止 —— 出膛一小段之后锁定直飞，目标横移就真的会打偏，保留「一点修正」的手感。

**冷却与重开语义**：结束引导会置 `needsRelease`，必须**先松开攻击键**才能再来一轮。
否则按住不放会在冷却结束的下一帧自动重开，「一次 5 波」就退化成挂机连发。

表现层同步：

- 飞弹改成**菱形梭形**（八面体沿飞行方向拉长 0.34 / 0.34 / 0.8），拖尾从「尾端 0.8 的喇叭」收成
  「靠核心 0.5、尾端 0.03」的细锥 —— 原来的拖尾比本体还宽，远看像三个水母；
- 池子 16 → 24（3 × 5 波，寿命 1.2s 内峰值约 18 枚）；
- 脚下进度弧改读**整轮进度**（`waveIndex + 当前波内比例` / `waves`），结束后显示 1s 青色冷却弧。

#### ② 弓箭：Core 自己算抛物线

以前箭是「表现层按 `attackId` 放一段匀速直线动画」，打没打中、飞多远都和 Core 无关。
现在箭是 Core 实体（`world.arrows`），表现层只按状态渲染：

```ts
ArrowState = { x,y,z, vx,vy,vz, life, stuck, stuckDummy, offX/offY/offZ, yaw, pitch, rest, hit }
```

- **出弓**：起点 = 角色身前 0.55m、高 0.95m；仰角固定 7°；初速 `9 ~ 16 m/s` 随蓄力线性插值；
  重力 `9 m/s²`。满蓄平地射程约 **11.9m**，最高点在出膛后 0.22s（约 1.19m）。
- **命中判定用线段而不是点**：满蓄单帧位移 0.33m，已和假人直径同量级，逐点检测会直接穿过去。
  现在对每个假人做「上一帧 → 本帧」的线段-圆柱最近点求交（同时校验高度），取最早相交的那个。
- **插住**：命中后存「相对假人的世界偏移」，每帧跟随平移 —— 但**不跟随转身**，
  否则假人原地转一圈会把插在肩上的箭甩成电风扇。落地则用 `supportHeight` 求脚下支撑面，
  所以箭能插在 0.8m 平台上、而不是穿进平台里。
- **驻留 4s** 后自动清理（`stickSec`），避免场地被箭插满。
- **蓄力时间 1.4s → 0.85s**，最小可发射蓄力 0.18 → 0.15：现在 0.3s 按住就能射出一支能用的箭。

#### 验收

- 新增 10 例：5 波 × 3 发计数、放完按住不重开、松手 + 冷却后可重开、波内散布角度、
  制导收敛 / 关掉 `turnRate` 保持原方向、蓄力时间、出弓仰角与重力、命中插身 + 跟随平移、落地插地 + 驻留清理、蓄满初速更快。
- 全量 **54 文件 / 627 例**通过；`verify:portable` PASS（Core 仍零 three / DOM / 上层依赖）。
- 实拍：三枚菱形飞弹各带细拖尾；5 波齐射时空中同时 9 枚分三排；弓在 0.13s / 0.33s / 0.57s 三个时刻
  的 y 高度为 1.13 / 1.05 / 0.51，落地时 `pitch = 0.28 rad`（约 16° 斜插）。
- 两处既有用例（`hip-yaw` / `attack-lower-body`）原本假设「按住就永远在引导」，
  现在把 `waves` 拉大以保持引导态 —— 它们测的是引导期间的下盘姿态，与波次节奏无关。

### v9s.18 · 接敌注视限速 + 俯仰，弓箭命中归属，奥术散开

> 三条反馈：① 接敌转头太快，头部要有俯仰注视并略略带一点身体俯仰，左右换目标时身体转向不平滑；
> ② 弓箭伤害判定有问题，有时没打到人也会多人受击 / 击退，另外打到哪根骨骼就该挂在哪根骨骼上；
> ③ 奥术飞弹出膛后先散开一点再飞向目标，彼此错落、速度慢些、各自索敌，本体不要自转。

#### ① 接敌注视：从「一帧到位」到「匀速扫视」

旧版威胁注视的身体 / 头部只是指数趋近（`bodyTurnRate 7`、`headTurnRate 30`）。指数曲线在角差大时
首帧就能吃掉 10% 以上的差距 —— 180° 的换目标，头部单帧直接甩 20°+，观感就是「头被瞬移」。
现在在指数趋近之外再套一层**角速度上限**（`approachCapped`）：

| 参数 | 默认 | 含义 |
|---|---|---|
| `gaze.bodyTurnRate` | 3.2 | 接敌时身体的指数趋近速率（1/s） |
| `gaze.maxBodySpeedDeg` | 130 | 身体最大角速度 |
| `gaze.headTurnRate` | 8 | 头部指数趋近速率 |
| `gaze.maxHeadSpeedDeg` | 300 | 头部最大角速度 |
| `turnInPlace.gazeTriggerDeg` | 120° | 接敌时原地转身的触发角（普通仍 50°） |

小角差仍是原来的指数手感，大角差退化成匀速扫视：实测左右换目标时**头部 5.0°/帧、身体 2.2°/帧**，
90° 左右的环视约 0.7s 转完，弧线不再有折点。

**为什么注视时要抬高原地转身的触发角**：`turnInPlace` 是一条固定 0.45s 的 ease 曲线，
一旦插进来就会「接管」bodyYaw、把平滑曲线切掉 —— 左右两个敌人来回切换时正好每 0.5s 切一次，
看到的就是一顿一顿的匀速块。现在只有真的绕到身后（> 120°）才播一次完整的转身踏步。

**俯仰注视**（`GazeState.mainPitch`）：注视点取主威胁**胸口高度**（`aimHeightRatio 0.75 × 假人身高`），
与玩家眼睛高度（`eyeHeightRatio 0.78 × characterHeight`）作差得仰角：

- `headPitch` 按 `headPitchRate 7` 追随，限幅 `maxHeadPitchDeg 28°`；
- `bodyPitch` = `headPitch × bodyPitchScale 0.3`，速率 `4`（比头慢一点）——「整个人抬眼看」，
  而不是头单独在脖子上折；
- 表现层在 `headPivot.rotation.x` 上取反（Core 约定 + = 抬头，three 的 rotation.x 正值是低头），
  `upper.rotation.x` 叠加身体俯仰；`headPivot` 的欧拉顺序改成 `YXZ`（先转头再点头，
  否则头转到侧面时俯仰会绕世界 X 轴，看起来像歪头）。

站在 1.2m 高台上、水平距离 3.97m 的敌人：`mainPitch = 0.436 rad（25°）`，`headPitch 0.436`、`bodyPitch 0.130`，
实测与配置一致。

#### ② 弓箭：多人受击的根因是「近战扫描」，插骨骼改为挂节点

`hits.playerHits` 是在 `attack-active` 事件上跑一次**扇形扫描**（`reach.bow = 9m`、`arcDeg 65°`）。
弓箭释放也会走 `windup → active`，于是放箭那一帧，前方 9m 扇形里的**所有**假人都会被结算一次受击 ——
箭还没飞出去，伤害已经发完了。这就是「没打到人却多人受击」，击退 / 受击动画随之一起出现。

修复只有一行判断：`if (cb.weapon === 'bow') return;` —— 弓箭的伤害唯一由箭实体（`arrows.ts`）结算，
一次放箭最多命中一个人（线段求交取最早相交）。

**插在哪根骨骼**分两层：

- Core 把命中点存成**假人局部坐标**（相对 `bodyYaw` 旋转），每帧再转回世界：
  `x = px + offX·cos + offZ·sin`、`z = pz − offX·sin + offZ·cos`，朝向也存 `localYaw`，
  于是假人**转身**时箭跟着一起转（旧版存世界偏移，转身会把箭甩出去）；
- 表现层 `dummy-rig.boneAtWorld(x,y,z)` 把命中点投到 10 段骨架线段（躯干 / 头 / 两臂各两段 / 两腿各两段）上，
  取最近的一段并返回它的节点，然后 `node.attach(arrowGroup)` —— `attach` 保留世界变换，
  所以挂上去的瞬间箭不跳，之后完全由骨骼带着走（摆臂、受击、步态都跟）。

#### ③ 奥术：错落出膛 → 散开 → 各自索敌

新版时序（全部在 Core，确定性、可快照）：

```
按下 → fireWave 生成 perWave 个 PendingShot（delay = i × spawnDelay）
     → 到点出膛（ProjectileState.spread = spreadTime）
     → spread 期间保持发射角直飞（散开）
     → spread 归零后每 retargetInterval 重新选一次最近目标（锥形内）并按 turnRate 限速转向
```

| 参数 | 默认 | 含义 |
|---|---|---|
| `spreadDeg` / `spawnSideStep` | 8° / 0.2m | 同波角度散布与横向出生偏移 |
| `spawnDelay` | 0.035s | 波内相邻飞弹的出膛间隔（错落） |
| `spreadTime` | 0.22s | 出膛后直飞散开的时长，期间不制导 |
| `speedJitter` | 0.12 | 每发速度浮动（纯函数哈希，不动 `rngState`） |
| `retargetInterval` | 0.25s | 飞行中重新索敌间隔 |
| `speed` / `life` | 10 m/s / 1.4s | 从 14 降下来，飞得更慢、看得更清 |

**各自索敌**：`candidates()` 按距离开火点排序，同一波的第 i 枚取第 `i % n` 近的目标，
飞行中再各自重选 —— 实测两个假人时分头追不同目标，而不是一窝蜂压向同一个点。

**本体不自转**：删掉 `core.rotation.y += dt·6` 的自转，只保留「组朝速度方向」的朝向，
菱形梭的尖头稳定指向飞行方向。

#### 顺带调整

- 出弓仰角 7° → **3.5°**：3m 内平射不再「擦着头顶过去」，命中点从头顶回到胸口（实测插点 y ≈ 0.98）。
- `applyHit` 里弓箭的受击类型分支删除（弓已不再走这条路径），`hits.reach.bow` 保留仅作调试读数。

#### 已知限制
