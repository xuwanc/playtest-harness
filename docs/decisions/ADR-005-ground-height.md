# ADR-005 · 贴地高度查询放 Core

- 状态：已采纳（v9s.38）
- 影响范围：`src/core/collision.ts`、`src/presentation/three-scene.ts`

## 背景

贴地特效（落点圈、电环、冲刺环、派生招光环、击地尘环）要知道「这个 XZ 上能站人的表面有多高」。直觉做法是在表现层写个射线或遍历 `boxes` 取 `maxY`，但那样表现层就拥有了地形知识。

## 决策

在 Core 里提供 `groundHeightAt(boxes, x, z, refY, fallback = 0, tol = 0.05)`：

- 从 `refY` 往下找**最高的实体表面**；
- `maxY > refY + tol` 的盒子（墙 / 过梁）忽略 —— 它们不是可以站的地面；
- 找不到就返回 `fallback`。

表现层只做一层包装：`groundFxY(x, z, fromY) = groundHeightAt(boxes, x, z, fromY + 0.55, 0)`。

## 为什么不是表现层私有工具

因为它是**空间查询**，与渲染无关。将来 Core 要做「落点是否可站立」「AoE 是否跨层」「闪现能否上台阶」，用的是同一个函数。放表现在，以后就得复制一份进 Core，然后两份行为漂移。

## 后果

- 表现层不再写死 `y = 0.03`，站上 0.2 / 0.6 / 0.9 / 1.2m 台阶时环落在顶面。
- **已知边界**：只看查询点正上方，不做半径内采样 —— 环跨台阶边缘时会一半埋进去。当前关卡所有高台都够大，按中心点取高是刻意取舍。
- 只支持轴对齐盒子；斜屋面 / 曲面不支持（当前关卡没有）。
- 单测：`tests/v9s38-fx-layer.test.ts` 覆盖阶梯、墙被忽略、无盒回落三种情况。
